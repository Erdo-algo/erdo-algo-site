# Erdo Algo website

Static, bilingual portfolio site for Erdo Algo. The interactive stress field is a synthetic explainer and is deliberately separated from the real Session Range Desk evidence case.

Live site: https://erdo-algo.github.io/erdo-algo-site/

## Local checks

```bash
npm run check
npm run serve
```

## Publishing

This directory is designed to be the root of a standalone GitHub Pages repository. The included workflow verifies the evidence boundary and deploys the site on every push to `main`.
